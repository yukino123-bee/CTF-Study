WINDOWS 10 & 11 · BEGINNER SETUP

Install Linux with WSL

Run Ubuntu and common CTF commands directly inside Windows—without dual booting or managing a traditional virtual machine.

About 10 minutes

The embedded video requires an internet connection. The written guide below remains available with the rest of the command hub.

01

Enable virtualization in BIOS/UEFI

Restart the computer and open its BIOS/UEFI setup by pressing the key shown during startup—commonly F2, Delete, Esc, or F10. Find the CPU, Advanced, Security, or System Configuration settings and enable Intel Virtualization Technology (VT-x), Intel VT-d, AMD-V, or SVM Mode, whichever your computer provides. Save the changes and restart Windows.

Tip: Menu names and startup keys vary by manufacturer. If the option is missing, check the computer or motherboard manual. In Windows, open Task Manager → Performance → CPU and confirm that Virtualization says Enabled.

02

Enable WSL

Open Start, search for Turn Windows features on or off, enable Windows Subsystem for Linux, select OK, and restart Windows when prompted.

On current Windows versions, you can instead open PowerShell as Administrator and install WSL and Ubuntu together.

wsl --install -d Ubuntu
03

Install Ubuntu

If you enabled the feature manually, install Ubuntu from the Microsoft Store. You can also list available distributions and install Ubuntu from PowerShell or Command Prompt.

wsl --list --online
wsl --install -d Ubuntu
04

Create your Linux account

Launch Ubuntu from the Start menu. The first launch finishes setup and asks for a Unix username and password. Password characters are intentionally not displayed while you type.

05

Open and leave Linux

Enter Linux from PowerShell or Command Prompt with wsl. Use exit to close the current Linux shell.

wsl
exit
06

Update Ubuntu for CTF use

Inside Ubuntu, refresh packages and install a useful set of basic CTF utilities.

sudo apt update && sudo apt upgrade -y
sudo apt install -y file binutils unzip zip p7zip-full curl wget git openssl python3 python3-pip netcat-openbsd nmap exiftool binwalk
06A

Package commands by Linux distribution

WSL supports more than Ubuntu. First identify the installed distribution, then use its package manager. Replace <package> with the tool you need; exact package names may differ between distributions.

cat /etc/os-release

Ubuntu / Debian / Kali

apt

Update:

sudo apt update && sudo apt upgrade -y

Install:

sudo apt install <package>

Fedora

dnf

Update:

sudo dnf upgrade --refresh -y

Install:

sudo dnf install <package>

Arch Linux

pacman

Update:

sudo pacman -Syu

Install:

sudo pacman -S <package>

openSUSE

zypper

Update:

sudo zypper refresh && sudo zypper update

Install:

sudo zypper install <package>

Alpine Linux

apk

Update:

sudo apk update && sudo apk upgrade

Install:

sudo apk add <package>
Important: Do not paste an apt command into Fedora, Arch, openSUSE, or Alpine. Search the distribution repository when a package cannot be found—for example, dnf search <name> or pacman -Ss <name>.
07

Access Windows files

Windows drives appear below /mnt. Your C: drive is available at /mnt/c. Quote paths that contain spaces.

cd /mnt/c/Users
ls
echo 'CTF ready' > ctf-ready.txt
08

Release WSL resources

Closing a terminal ends that shell, but WSL may continue running. From PowerShell or Command Prompt, stop all distributions and release their RAM:

wsl --shutdown
✓

You are CTF-ready

Open Ubuntu, move to your challenge folder under /mnt/c, and use the searchable commands in this hub.
